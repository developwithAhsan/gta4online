QUESTIONS & ANSWERS

GTA IV FAQ

Can I play GTA IV in this browser right now?＋

Not yet. A compatible GTA IV browser game client has not been connected to this portal. This website currently provides information, controls and guides.

Is this an official Rockstar Games website?＋

No. This is an independent fan-made information project and is not affiliated with Rockstar Games or Take-Two Interactive.

Are these the default GTA IV PC controls?＋

They follow the default PC keyboard and mouse layout documented for GTA IV. You can customize controls from the in-game settings menu.

Will the mobile buttons control the game?＋

The touch overlay provides the interface. A compatible game client must implement the input bridge before touch actions can affect gameplay.

Does this website host GTA IV game files?＋

No. No game files are hosted or distributed here. Use a legally obtained copy of Grand Theft Auto IV.

Can I use fullscreen on a phone or Chromebook?＋

Fullscreen depends on the browser and device. Rotate Screen requests landscape where the browser supports orientation locking; manual rotation may still be required.
