GTA IV Portal Features: Controls, Layout, and Guides

A tour of the GTA 4 Online portal, its Liberty City-inspired design, keyboard and touch controls, and helpful game information.

Live gameplay status: A compatible, authorized GTA IV browser game client is not connected to this website yet. The page is an information portal and control interface; it does not stream or host the original game.

The GTA 4 Online Web Edition is an independent fan-made portal for Grand Theft Auto IV information. The layout keeps the main game-status panel near the top and places controls, project details, guides, community feedback and FAQs below it.

A clear portal landing area

The main panel introduces Liberty City and shows whether a compatible game client is available. At present, the status message explains that no client is connected. There are no third-party game embeds, custom game URLs or unverified download buttons.

GTA IV keyboard and mouse controls

The controls reference is organized into general actions, on-foot movement and vehicle actions. It lists common PC bindings such as WASD movement, Left Shift sprint, Space jump and handbrake, F to enter or leave vehicles, E for action, R to reload, and mouse buttons for attack and aim. Bindings can be changed in the game's own settings.

Mobile touch controls

Touch devices can open the on-screen controls overlay. It includes a movement joystick, action buttons, and vehicle-specific buttons. The controls panel also supports opacity, size, camera sensitivity, haptics and a left-handed layout. The overlay needs a compatible GTA IV client that implements its input bridge before it can send actions into gameplay.

Fullscreen and landscape mode

The Fullscreen control requests browser fullscreen for the game area. Rotate Screen also requests landscape orientation where the device and browser allow it. Some browsers do not permit orientation locking, so rotating the device manually may still be necessary.

Guides, FAQs and project information

The blog contains articles about control layouts, accessibility, device compatibility, performance, safety, privacy and troubleshooting. The About, Privacy, Terms and Contact pages explain the project's independent status and how to report site issues.

What this website does not provide

This project does not include GTA IV game data, a game engine, online multiplayer servers or a downloadable copy of Grand Theft Auto IV. Use a legally obtained copy of the game.
