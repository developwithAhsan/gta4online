GTA IV PC System Requirements: CPU, RAM, GPU and Storage

Check Rockstar's official GTA IV PC minimum requirements, Windows version, CPU, RAM, graphics card, storage, activation needs and compatibility warnings.

Updated November 18, 2026 · GTA 4 Online Web Edition

Before installing Grand Theft Auto IV on a Windows PC, compare your hardware with Rockstar's published minimum specifications and read the additional activation and software requirements. Meeting the minimum does not guarantee smooth performance, especially on older integrated graphics or mobile chipsets.

Important distinction: GTA 4 Online Web Edition is an information portal. It does not host, distribute or connect the third-party WebGPU port or the original GTA IV game files.

Rockstar's published minimum PC requirements

Rockstar lists Windows 10 64-bit as the operating system, an Intel Core 2 Quad Q6600 at 2.40 GHz or an AMD Phenom 9850 Quad-Core at 2.5 GHz, 2 GB of RAM, and a 512 MB NVIDIA 8600 or 512 MB ATI 3870 graphics card. The published storage requirement is 22 GB of available hard-drive space. Rockstar also lists a DirectX 9.0c-compatible sound card and mouse and keyboard input, with a controller recommended.

These are minimum requirements, not a modern recommended configuration. The game may run with limitations on hardware that barely meets them. Rockstar warns that some mobile chipsets, integrated graphics adapters and AGP graphics cards may be incompatible, and unlisted specifications may not be supported.

Additional installation and activation requirements

Rockstar's support page says installation and online play require an internet connection and a Rockstar Games account. Its listed requirements include the Rockstar Games platform, DirectX, Chromium, Microsoft Visual C++ 2008 SP1 Redistributable and authentication software. A single-use serial code must be registered online and is tied to one account after activation.

Account and activation rules can change, so check Rockstar's current support instructions before installing an old retail copy or moving an activated account. A physical disc, old launcher or pre-Complete Edition guide may describe an earlier installation flow.

Steam and physical-disc installation notes

Rockstar's Steam installation guidance says owners should update an existing GTA IV installation to Grand Theft Auto IV: Complete Edition. The update includes content from Episodes from Liberty City and can require an additional download of about 6 GB. Make sure your internet connection and storage can accommodate the update, not just the base 22 GB minimum.

For physical-disc owners, Rockstar's April 2026 support guide describes activating and updating the disc installation to Complete Edition using the activation code from the game manual and the Rockstar Games Launcher. Follow the steps for your own edition rather than mixing Steam and disc instructions.

How to check your Windows PC

Open Windows Settings and check System > About for the Windows edition, processor and installed RAM. Open Device Manager or Windows Task Manager to identify the installed graphics adapter. Check File Explorer for available space on the drive where you intend to install the game. Compare each item with Rockstar's requirement list rather than relying on a generic “gaming PC” label.

For a laptop with both integrated and dedicated graphics, confirm which adapter the game uses and check the manufacturer's driver support. Close unnecessary applications during testing, keep the device cool and change graphics settings one at a time. A 2 GB minimum memory figure should not be treated as enough for every modern Windows background workload.

Does meeting the requirements mean it runs in a browser?

No. Rockstar's requirements are for the Windows PC release. A normal website cannot run the original PC game just because the browser meets those hardware numbers. Cloud streaming uses a remote computer and depends on the provider's catalogue, region, network delay and supported devices.

The separate community WebGPU port has different requirements: its own README documents a supported USA Xbox 360 disc image, Title Update 8, Python 3, a Chromium browser with WebGPU, and browser storage for the first install. Read the dedicated GTA IV WebGPU browser-port guide for those requirements.

Key takeaway: Use Rockstar's published minimum requirements as the starting point, then check activation, software dependencies, GPU compatibility and update space. Minimum specifications do not guarantee performance.
