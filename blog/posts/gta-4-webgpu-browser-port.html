GTA IV in Chrome: WebGPU Browser Port Setup, Requirements and Limits

Learn how the community GTA IV WebGPU port works, the original Xbox 360 disc and update it requires, supported browsers, setup steps and device limitations.

Updated November 18, 2026 · GTA 4 Online Web Edition

A community project now makes it possible to run a recompiled Xbox 360 version of Grand Theft Auto IV in a Chromium browser using WebAssembly and WebGPU. This is not a built-in feature of GTA 4 Online Web Edition. The project requires your own compatible game media, a local Python server, a supported browser and substantial browser storage. Read the requirements before downloading anything.

Important distinction: GTA 4 Online Web Edition is an information portal. It does not host, distribute or connect the third-party WebGPU port or the original GTA IV game files.

What the WebGPU browser port actually is

The independent project `itzzace/gta4-web` recompiles the Xbox 360 version of GTA IV to WebAssembly and renders it using WebGPU. It is built on earlier community recompilation work and provides a small local launcher that serves the files to Chrome or Edge. The first launch installs the game data into browser storage; later launches can reuse that local installation.

The project does not ship the commercial game files. It expects the user to provide a compatible USA Xbox 360 disc image and the specified Title Update 8 data. This is different from a cloud gaming website that streams a game from a remote server, and it is different from a native PC installation.

Requirements before you begin

The project's current instructions call for a USA Xbox 360 GTA IV disc image (`.iso`), Title Update 8, Python 3, and a current Chrome or Edge browser with WebGPU support. The documented initial installation uses around 8 GB of browser storage. Keep additional free disk space available for the extracted project and local game media.

The project says Safari, Firefox, iPhone and iPad browsers are not supported at this time. Do not assume every Chromebook or phone is compatible: the latest v0.1.8 performance notes describe a fast Mac slowed down to simulate a low-end device, not a test on a real Chromebook or phone. Verify the browser using the project's own compatibility checker before relying on it.

How the setup process works

1. Download the latest release archive from the project's official GitHub Releases page, not from a third-party mirror. 2. Install Python 3 from its official source. 3. Extract the release archive. 4. Place your own supported USA Xbox 360 ISO and Title Update 8 data in the `game-files` folder exactly as the project documentation specifies. 5. Launch the supplied Play GTA IV script for your operating system. 6. Keep the small local server window running and open the local address that the launcher provides in Chrome or Edge.

The first run transfers and installs the supplied local game data into browser storage and may take several minutes. Keep the game tab in the foreground while installation runs; background tabs can be throttled by the browser. The game then loads from browser storage on later sessions. Follow the release README because file names and requirements can change between versions.

Controls, saves and device limits

The project documents keyboard and mouse input, controller support, fullscreen, an FPS counter, browser saves and save export/import tools. Those features belong to the third-party WebGPU port, not this GTA 4 Online information portal. Check the release notes for the exact version before relying on a particular control or save feature.

A PC browser with WebGPU support is the documented target. The project does not claim tested support for every Chromebook, Android device or phone. Older hardware can have limited memory, and browser storage quotas vary by device and profile. Close unused tabs and make sure there is enough free storage before trying a large first install.

Safety, ownership and troubleshooting

Use only game media you are legally entitled to use and follow the licence and laws that apply where you live. Do not download or share disc images, title updates or game archives from unofficial file-sharing pages. The community repository states that it does not include the game files and publishes its web-port code under GPL-3.0.

If the launcher reports a missing disc image, verify that you supplied the supported USA Xbox 360 image rather than a PC or PlayStation edition. If the browser reports a WebGPU or storage problem, use the project's compatibility checker and official issue tracker. Do not disable browser security or install unknown “fix” executables.

How this relates to GTA 4 Online Web Edition

This website is a separate information portal. It does not host the WebGPU port, game engine, Xbox 360 disc image, Title Update 8 or a remote gameplay server. The controls panel and screenshots on this site are reference features only. To use the community port, visit its official project pages and follow that project's own setup instructions.
