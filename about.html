ABOUT THIS PROJECT

AN INDEPENDENT
GTA IV PORTAL.

GTA 4 Online Web Edition is an independent information portal for Grand Theft Auto IV, with a responsive layout, PC controls reference, mobile touch interface, device guidance and practical guides. It includes a responsive portal shell, PC controls reference, mobile touch interface, device guidance and practical guides.

Current game-client status

A compatible, authorized GTA IV browser client has not been connected to this website. The site does not host, stream or distribute the original game files. Touch inputs will only reach a game after a compatible client implements the documented input bridge.
